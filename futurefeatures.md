# Future features

Planned ideas for future development. Unchecked items are not yet implemented.

- [ ] **Complex asteroid shapes:** give asteroids irregular outlines instead of simple circles.
- [ ] **Background visuals:** add a space background, such as stars or moving scenery.
- [ ] **Entity sprites:** add actual sprites for the player, asteroids, projectiles, and powerups.
- [ ] **Propulsion rendering:** show engine thrust when the player accelerates.
- [ ] **Lives:** allow the player to lose a life and respawn before the round ends.
- [ ] **Leaderboard:** record and display high scores.
- [ ] **Mouse-clickable main menu:** add buttons that respond to mouse clicks.
- [ ] **Settings menu:** allow players to configure the game, including screen resolution.
- [ ] **Sound effects:** add audio for firing, hits, asteroid destruction, upgrades, and player death.
- [ ] **Fullscreen:** support playing in fullscreen mode.
- [ ] **Pause screen:** pause gameplay, display the current score and player stats, and offer options to resume or exit to the main menu.
- [ ] **Weapon-change upgrade:** add an upgrade type that changes the weapon and its firing behavior.
